日报 20260428：适配一人公司！家庭局域网 AI 工作台来了

我正式开始 vibe coding 了一款本地专属 AI 工作台——不用连公网，只在家庭局域网里用，就能把电脑、家庭服务器里的资源全整合，告别翻文件夹找文件的麻烦。

它到底能做什么？

核心就是可视化一站式管理，不用在系统里层层点开目录，所有资源直接平铺展示，还能快速搜索。

目前已经做了 4 个核心功能：

  • 仪表盘——打开就能看数据，后续会用图表展示财务、AI Token 消耗、健康状态等信息，一目了然；
  • 资源库——管齐本地文件、本机 Web 服务，还能连家里局域网其他设备，比如 Mac mini 的影音服务器、Windows 的下载服务器，直接在页面访问；
  • Git仓库——电脑里所有 Git 仓库直接列成清单，不用一层层找文件夹，点开就能用；
  • 本地知识库——用 Markdown 记内容、YAML 存扩展数据，本地文件可视化展示，比纯文件夹管理更直观。

设计上的小巧思

  • 子应用切换放在系统名旁边，像主站带子品牌一样，逻辑更清晰；
  • 用户系统是数字人格身份，后续会和自研互联网名片 LinXoid 打通，还能管理智能体、数字身份，支持人和智能体协作。

谁适合用它？

  • 一人公司（AIOPC）、超级个体、自由职业者；
  • 重视数据管理的个人与家庭；
  • 家庭服务器（Home Lab）玩家。

还能这样玩

系统能和飞书机器人打通，本地服务完成任务后，会自动发通知到绑定🦞的飞书机器人，手机上就能一站式接收信息与遥控操作。

接下来的优化

马上重构界面，引入组件库和图标库，把视觉和交互做得更好用。
